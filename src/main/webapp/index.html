Delivery Management API

Customer

GET /api/customers - Get all customers
GET /api/students/{id} - Get customer by FirstName
POST /api/students - Create new student
PUT /api/students/{id} - Update student
DELETE /api/students/{id} - Delete student

MenuItems

GET /api/menuitems - Get all menuitems
GET /api/menuItems?min=X&max=Y - Filter by price range
GET /api/menuitems/{name} - Get MenuItem by name
POST /api/menuitems - Create new MenuItems
PUT /api/menuitems/{name} - Update MenuItem
DELETE /api/menuitems/{name} - Delete MenuItem

Built with Java Servlets, Jackson, SLF4J/Logback
